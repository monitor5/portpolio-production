# 실제 사진 촬영·제공 가이드

2026-09-21. 사진은 김우현 본인과 실제 사용한 장비를 촬영한 자료를 사용한다. 모든 사진을 한 번에 준비할 필요는 없다.

## 먼저 필요한 세 가지

### 1. 작업 공간에서의 인물 사진

- 용도: 홈의 “계속 배우는 김우현입니다” 소개.
- 구도: 상반신 또는 작업 중인 옆모습. 책상이나 장비가 배경에 조금 보이도록.
- 비율: 세로 4:5, 머리와 어깨 주변에 여백. 전체 인물 파일 원본도 함께 보관.
- 촬영: 창가의 부드러운 자연광. 과한 보정·필터 없이 자연스럽게.
- 인물 대신 시작하려면: 장비를 만지는 손과 작업 공간 사진도 가능.
- 연결 위치: `src/media.js`의 `portrait`.

### 2. 대표 홈 서버 사진 한 장

- 용도: 홈의 HW/Server 프리뷰와 장비 상세.
- 우선순위: TR 2990WX 실제 구성 또는 듀얼 EPYC 내부.
- 구도: 가로 4:3. 전체 케이스·내부 구성·주변 환경을 알아볼 수 있게.
- 듀얼 EPYC는 두 소켓과 메모리 구성이 보이는 사선/상단 사진이 좋다.
- TR은 케이스와 함께 쓰던 NAS·전원 구성이 담기면 이야기를 연결하기 좋다.
- 과거 사용 당시 사진이 있으면 그대로 사용한다. 현재 사진은 촬영 시점을 따로 구분한다.
- 연결 위치: `threadripper` 또는 `epyc`.

### 3. 노트북 개조 전후

- 용도: “케이스와 냉각에도 손을 댔습니다” 상세.
- 구도: 개조 전후를 비슷한 각도·거리에서 한 장씩. 개조 부위 근접 사진 추가.
- 강조할 부분: 바꾼 케이스, 냉각 구조, 연결·가공한 흔적.
- 완벽하게 정리된 제품 사진보다 직접 손댄 부분이 잘 보이는 사진이 유용하다.
- 연결 위치: `laptop`. 전후 사진을 여러 장 받으면 상세 갤러리로 확장.

## 이후 추가하면 좋은 자료

- **BC-250 두 대:** 두 장비를 나란히 놓은 상단 사진. 단순한 배경에 측면 여백 확보.
- **자작 NAS:** 전체 모습과 내부 부품 배치 각 한 장.
- **책:** 표지가 잘 보이는 사진 또는 출판사가 제공한 표지 이미지.
- **작동 영상:** 실제 장비가 켜진 상태의 5~8초 고정 영상. 과거 장비를 재현하는 가짜 영상은 사용하지 않는다.

## 파일 전달

- 가능하면 원본 해상도. 긴 쪽 2,000px 이상이면 다양한 화면에 쓰기 좋다.
- 메신저 캡처나 화면 캡처보다 원본 사진 파일을 우선한다.
- 장비명·촬영 시점·직접 바꾼 부위를 한두 문장으로 함께 알려주면 캡션 작성에 도움이 된다.
- 촬영 전에 화면의 계정 정보와 개인 문서 등 공개하지 않을 내용을 정리한다.

## 구현 상태

`src/media.js`의 사진 경로는 현재 모두 `null`이다. 존재하지 않는 이미지 주소를 넣거나 가짜 장비 사진을 보여주지 않는다. 경로가 채워지면 홈랩 카드와 장비 상세, 인물 소개가 사진을 포함하는 레이아웃으로 전환된다.

```js
export const photos = {
  portrait: '/assets/portrait.webp',
  threadripper: '/assets/threadripper.webp',
  epyc: null,
  bc250: null,
  nas: null,
  laptop: '/assets/laptop.webp',
};
```

위 경로는 제공 후 사용할 파일명 예시다. 실제 사진을 받기 전에는 설정하지 않는다. 원본은 별도로 보관하고 사이트에는 크기와 용량을 최적화한 사본을 사용한다.
