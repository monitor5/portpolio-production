# cwaitt.dev를 참고한 Apple 스타일 방향

2026-09-21. 사용자 지정 레퍼런스: [Chris Waitt](https://cwaitt.dev/). 첫 화면과 프로젝트 섹션을 실제 브라우저에서 확인했다.

## 디자인 변경

- 중앙 정렬된 이름·직무와 큰 소개 문구.
- 푸른색에서 보라색으로 이어지는 절제된 그라데이션 타이포그래피.
- 화이트·실버 기본 톤과 다크 모드 전환.
- 얇은 반투명 상단 메뉴와 둥근 주요 버튼.
- 실제 서비스 화면을 크게 보여주는 프로젝트 카드.
- 넓은 여백, 간결한 본문, 사진과 내용이 중심인 홈랩·출판 카드.

레퍼런스의 구성 원칙을 참고했으며 개인 문구·프로젝트·사진은 복제하지 않았다. 기존 사용자 요구인 세로 스토리와 분야별 독립 상세는 유지한다.

## 홈의 흐름

1. **삽질부터 AI까지. 호기심으로 이어봅니다.** 이름·직무·소개, 프로젝트와 홈랩 진입.
2. **여행갈매기:** 실제 화면, 팀장·백엔드·AI·서버 담당, 1주일, 수상과 부산교통공사 지원 배포.
3. **APPLIED AI:** 『LLM 활용과 국방』의 실제 표지와 책 상세로 연결. 옆에는 Tapo Control을 배치.
4. **홈랩:** “삽질하다 보니, 점점 커졌습니다.” 기종별 큰 숫자 대신 제목·경험 요약·작은 사용 기간으로 구성한다. 링크는 “HW 삽질 스토리 보러가기”.
5. **논문과 책:** 두 개의 카드와 상세 서지 정보. 홈에서 수상·공동저자·공저자 강조 배지는 제거했다.
6. **사람:** 사진·카메라·음향에 대한 관심과 학적. 본인 사진을 받으면 왼쪽 사진·오른쪽 소개로 전환.

소개가 반복되던 별도 “호기심” 단락을 줄였고, 확인되지 않은 활성 사용자 수·개인 성과를 암시하는 문구를 보강하지 않았다.

## 사진 구성

우선 사진은 인물 1장, 대표 서버 1장, 개조 노트북 전후다. 구체적 촬영 가이드는 [사진 요청서](photo-brief.md)에 있다. 실제 사진을 받기 전에는 사진이 없는 타이포그래피 레이아웃으로 표시한다.

`src/media.js`에서 사진 경로를 관리한다. 홈랩 카드·장비 상세·About 모두 제공된 사진에 맞게 확장할 수 있다. 여행갈매기는 기존의 실제 서비스 화면을 계속 사용한다. APPLIED AI와 도서 상세에는 실제 출판사 표지를 사용한다.

표지 출처: [커뮤니케이션북스 일반판 이미지](https://commbooks.com/cbhome/wp-content/uploads/2026/04/9791143025302-545x800.jpg), ISBN 9791143025302. 로컬 자산: `public/assets/llm-defense-cover.jpg`.

## 구현 범위

- 4개의 메인 경로와 프로젝트 6개·하드웨어 5개·출판 2개 상세 유지.
- 테마 전환은 로컬 브라우저에 저장되며 페이지 이동 후에도 유지.
- 프로젝트 필터, 뒤로가기·스크롤 위치 복원, 모바일 메뉴 유지.
- About 메뉴는 홈의 소개 위치로 직접 이동.
- 로컬 미리보기는 `http://127.0.0.1:4387/`. 외부 배포는 하지 않았다.

이 문서와 구현 코드가 현재 시각 디자인 기준이다. 이전의 검정·연두색 편집형 시안은 디자인 이력으로 남긴다.

## 다국어 지원

영어를 기본으로 한국어·일본어 전체 페이지를 제공한다. 언어 메뉴는 상단에서 언제든 열 수 있고, 현재 경로·앵커·필터·읽던 위치·테마를 유지한다. 자세한 규칙은 [다국어 문서](i18n.md)를 따른다.
