# 하드웨어·홈랩 서사

근거: 사용자 지원서와 후속 설명. 하드웨어·서버에 대한 관심을 포트폴리오의 중심 캐릭터로 유지한다는 사용자 방향을 반영했다.

## Lab의 핵심 소개

> **하드웨어·서버 변태, 김우현입니다.**
>
> 컴퓨터를 뜯고, 서버를 굴리고, AI 서비스를 만듭니다.

TR 2990WX를 4년 동안 사용한 경험을 큰 줄기로 삼는다. EPYC를 집에 들여 직접 실험한 4개월, BC-250 두 대를 구입한 일, NAS를 직접 구축하고 노트북의 케이스와 냉각까지 개조한 경험으로 그 성격을 구체적으로 보여준다.

이야기의 연결은 **궁금해함 → 직접 장비를 구성하고 사용함 → 관찰하고 고침 → AI 실험과 서비스 개발에 이어짐**이다. 이 연결은 편집 방향이며, 장비들의 시간 순서는 정확한 연월을 받은 뒤 정리한다.

## 다섯 가지 중심 이야기

| 이야기 | 확인된 사실 | 글의 초점 | 추가로 채울 내용 |
| --- | --- | --- | --- |
| TR 2990WX와 보낸 4년 | 해당 장비 4년 사용. 군 복무 중 원격 공유 환경에도 활용 | 한 장비와 오래 지내며 생긴 사용·운영 경험 | 구입 이유, 작업 종류, 시기별 구성과 변화 |
| 집에서 듀얼 EPYC를 굴린 4개월 | EPYC 4개월 사용. 지원서에 듀얼 7452·RAM 240GB, AI 실험과 전기요금 경험 서술 | 가설 때문에 실제 서버를 들이고 확인한 과정 | 모델·실험 조건, 결과, 전력·소음·비용과 사용 종료 이유 |
| BC-250을 두 대 산 이야기 | 두 대 구매 | 특이한 장비를 고르게 된 호기심 | 구매 동기, 실제로 해본 작업, 연결·구동 여부 |
| 직접 만든 NAS | 직접 구축 경험 | 필요한 환경을 자기 손으로 만드는 과정 | 부품, OS, 저장 구성, 데이터 용도, 운영 문제 |
| 케이스와 냉각을 개조한 노트북 | 케이스·냉각 솔루션 직접 개조 | 기계의 물리적인 구조에도 손을 대는 성향 | 기종, 원래 불편, 가공·냉각 변경, 전후 관찰 |

TR 4년·EPYC 4개월은 각각의 사용 기간이다. 두 기간을 더해 총경력으로 쓰지 않는다. BC-250 두 대 구매만으로 클러스터 구축이나 AI 구동에 성공했다고 쓰지 않는다. 세부 이야기는 사용자가 실제로 한 일을 바탕으로 채운다.

## 홈페이지에 보이는 모습

1. **첫 화면:** 직무·성과와 하드웨어 프리뷰 2~3개. 작동 모습과 짧은 캡션으로 캐릭터를 보여주고 Lab으로 연결한다.
2. **세로 이야기:** 소개 → 만드는 방식 → 실제 서비스 → 하드웨어 → 연구·출판 → 사람. 상단 Projects / HW·Server / AI·Research는 독립된 분야별 페이지로 이동한다.
3. **Lab 페이지:** 다섯 항목을 사진·사용 기간·짧은 이야기로 소개한다. TR을 중심 장비로 가장 크게 배치한다.
4. **홈랩 상세 `/lab/<이야기>`:** 장비를 고른 이유, 사용·개조 과정, 관찰과 다음 시도를 세로로 충분히 읽게 한다.

홈랩의 존재는 첫 공개 범위에 포함한다. 상세 자료가 적은 항목은 확인된 사실과 사진부터 보여주고, 긴 글은 이후 채운다.

## 사진과 표현

- 실제 사용했던 TR·EPYC 시스템 전체 사진과 내부 사진.
- 두 대의 BC-250을 함께 볼 수 있는 사진.
- 직접 만든 NAS의 부품 배치와 케이스.
- 노트북 개조 전후, 바뀐 케이스·팬·방열 구조의 근접 사진.
- 당시의 작업 책상, 배선, 실험 기록처럼 사용한 흔적이 드러나는 자료.

사진은 사용자가 전부 제공한다. 메인은 일부 프리뷰, Lab은 전체 모습·세부·전후 사진으로 깊이를 나눈다. 아직 자료가 없는 구성안에서는 사진 자리만 표시한다. 작동 영상이 제공되면 정지 제어와 사진 대체를 포함해 선택적으로 사용한다. 장비 사진은 특정 부품이 무엇이며 본인이 어디를 바꿨는지 설명하는 캡션과 함께 배치한다.

문체는 개인적인 이야기에 맞게 솔직하고 약간 장난스럽게 쓴다. “하드웨어·서버 변태”라는 자기소개를 유지하고, 상세 본문에서는 장비·행동·관찰을 구체적으로 설명한다. 소개 전체를 기술 키워드로 바꾸지 않는다.

## 살려둘 에피소드

- 초등학교 5학년 때 컴퓨터를 직접 조립하고 오버클럭을 시도한 경험.
- 일체형 PC 방열 구조를 바꾸고 VM을 돌린 경험.
- 폐기장에서 가져온 Dell X58 서버의 팬 소리.
- X79를 박스에 넣고 글루건을 써 친구 서버를 만든 일.
- TR·NAS·스마트 플러그를 이용한 원격 개발 환경.
- CPU 메모리 대역폭에 대한 궁금증으로 구성한 듀얼 EPYC와 한 달 전기요금 48만 원 경험.

모두 사용자 지원서에 나온 소재다. 비용은 해당 월의 경험으로 쓰고 장비 단독 소비전력 측정치로 환산하지 않는다. 노트북 개조와 과거 일체형 PC 개조는 별도로 다룬다.

## 다른 콘텐츠와의 연결

- **Tapo 원격 전원 제어:** 장비를 함께 쓰며 필요한 소프트웨어를 만든 사례로 연결.
- **AI·ML:** 모델을 돌릴 환경을 직접 구성하고 자원 제약을 겪은 배경으로 연결. 실제 실험 결과를 얻은 범위로 작성.
- **여행갈매기:** 개인 서버 경험 이후 팀에서 AI·백엔드·서버를 맡은 현재의 작업을 보여줌.
- **논문·도서:** LLM 활용의 문제를 연구하고 글로 정리한 별도의 성과로 제시.

터보퀀트처럼 실질적인 작업이 거의 없었던 외부 자료 기반 항목은 계속 제외한다. 직접 시도하고 관찰한 하드웨어 경험은 실패하거나 미완성이어도 충분히 다룬다.
