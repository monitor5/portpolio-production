## 디자인 방향

- 검정·밝은 중립색 바탕과 선명한 연두색 한 가지 강조색.
- 큰 타이포그래피, 큰 여백, 선으로 구분하는 정보 구조.
- 홈은 자연스러운 세로 스크롤. 강제로 화면이나 휠 방향을 바꾸지 않는다.
- 고정 메뉴: Story / Projects / HW·Server / AI·Research.
- 분야별 페이지와 개별 상세는 독립된 주소로 열고, 브라우저 뒤로가기를 지원한다.
- 하드웨어는 사용 기간·실제 경험을 먼저 보여준다. 사용자가 사진을 제공하면 해당 장비 기록에 통합한다.
- 이전 시안의 프레임·다섯 장 슬라이더·둥근 빈 사진 카드는 사용하지 않는다.

## 홈의 이야기

1. **호기심을 작동하는 것으로.** 이름·지원 분야와 수상·논문·출판 근거.
2. **궁금한 게 생기면 직접 해보기.** 컴퓨터 조립에서 서버·소프트웨어로 이어지는 배경.
3. **만든 것이 실제 서비스로.** 여행갈매기 실제 화면, 개인 역할, DIVE 2026 발제사 2등상, 부산교통공사 지원 배포.
4. **서버가 집에 있으면 벌어지는 일.** TR 4년·EPYC 4개월·BC-250 두 대와 별도 Lab 진입.
5. **질문은 실험으로, 생각은 글로.** KCI 논문과 출간 도서.
6. **함께 배우는 사람.** 학적·동아리·관심사와 GitHub 연락 경로.

## 로컬 구현과 실행

기존 포트폴리오 작업 폴더에 Vite 기반 HTML·CSS·JavaScript로 구현했다. `src/data.js`에 프로젝트·장비·출판 데이터를 모았다.

```sh
npm install
npm run dev
npm run build
```

미리보기: `http://127.0.0.1:4387/`. 이번 변경은 로컬 디자인 구현이며 외부 호스팅에 배포하지 않았다. 이후 공개 시에는 SPA 상세 경로가 `index.html`로 연결되도록 호스팅을 설정한다. `notes/private/`는 사이트 소스에서 읽지 않으며 빌드에 포함하지 않는다.
