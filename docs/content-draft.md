**김우현**

**삽질부터 AI까지. 호기심으로 이어봅니다.**

호기심이 생긴다면, 직접 구상하고 실험하여 원하는 것들을 만들어봅니다.

집에 서버를 들이고, 궁금한 것은 직접 확인합니다. 여행갈매기에서는 팀장을 맡아 AI·백엔드·서버를 개발했습니다.

캐릭터 문구: **하드웨어·서버 변태의 기록 → Lab**. 장비의 작동 모습은 사진 제공 후 세로 이야기 안에 통합하고, 아래의 다섯 장비 이야기는 별도 Lab에서 충분히 보여준다.

## 집에서 굴린 것들 · 홈랩

세로 스토리 홈의 하드웨어 구역과 독립 목록 `/lab`, 개별 상세로 구성한다. 각 항목을 사용자가 제공하는 실제 장비 사진과 한두 문장으로 보여주고 [하드웨어·홈랩 이야기](hardware-story.md)의 상세 원고로 이어간다. 사진을 제공받으면 홈의 하드웨어 구역에 일부 프리뷰를 배치한다.

| 항목 | 카드 문구 초안 |
| --- | --- |
| TR 2990WX · 4년 사용 | 오랫동안 곁에 둔 장비입니다. 군 복무 중에는 NAS와 스마트 플러그를 연결해 친구와 공유하는 원격 개발 환경으로도 사용했습니다. |
| EPYC · 4개월 사용 | CPU 메모리 대역폭으로 AI를 어디까지 돌릴 수 있을지 궁금해, 집에 듀얼 EPYC 서버를 구축해 직접 실험했습니다. |
| BC-250 · 두 대 구매 | BC-250도 두 대 샀습니다. 어떤 용도로 골랐고 실제로 어디까지 써봤는지는 다음 이야기로 채웁니다. |
| 직접 만든 NAS | 필요한 저장 환경도 직접 만들어봤습니다. 구성과 사용 과정을 사진과 함께 소개합니다. |
| 케이스·냉각을 개조한 노트북 | 노트북은 케이스와 냉각 솔루션까지 직접 손봤습니다. 어느 부분을 어떻게 바꿨는지 개조 전후를 보여줍니다. |

편집 메모: BC-250의 선택 이유·실제 작업과 NAS·노트북의 구체적인 구성은 아직 수집 전이다. 카드의 자료 수집 안내 문장은 실제 이야기를 받은 뒤 교체한다. TR 4년과 EPYC 4개월은 각각의 사용 기간이며, 정확한 선후관계·중복 사용 시기는 미확인이다.

## About 초안

저는 스스로를 하드웨어·서버 변태라고 소개합니다. 초등학교 때 컴퓨터를 조립하기 시작했고, 궁금한 게 생기면 기계를 뜯거나 직접 환경을 만들어 확인해 왔습니다. TR 2990WX를 4년 동안 사용했고, 듀얼 EPYC 서버를 집에 들여 4개월간 써보기도 했습니다. BC-250 두 대, 직접 구축한 NAS, 케이스와 냉각을 개조한 노트북까지, 제 관심은 늘 실제 장비로 이어졌습니다.

군 복무 중에는 TR 2990WX와 NAS, 스마트 플러그를 조합해 친구와 공유하는 원격 개발 환경을 운영했습니다. AI를 돌려보고 싶어 서버를 구성하고, 필요한 기능이 생기면 프로그램을 만드는 식으로 하드웨어와 소프트웨어를 함께 배웠습니다. 성능뿐 아니라 발열과 전력, 비용처럼 직접 써야 마주치는 문제에도 관심이 많습니다.

학부연구에 참여하며 데이터 정리와 CNN 구조의 학습·적용을 경험했고, 군 복무 중에는 국방 분야의 LLM 활용 문제를 연구해 논문과 책의 공동저자로 참여했습니다. 최근에는 팀 프로젝트에서 AI 기능과 백엔드, 서버를 맡아 서비스를 구현하고 있습니다.

실패한 시도도 다음 판단의 근거로 남기고 싶습니다. 함께 개발할 때는 무엇을 만들었는지뿐 아니라, 왜 그렇게 설계했고 어디서 막혔으며 어떻게 확인했는지를 설명할 수 있는 개발자가 되려 합니다.

편집 메모: 학부연구의 CNN 프로젝트와 국방 LLM 논문은 별개 경험이다. 같은 연구이거나 CNN 연구가 해당 KCI 논문으로 이어졌다고 표현하지 않는다.

1. **TR 2990WX와 보낸 4년** — 장기간 사용한 이유, 시기별 용도, 원격 공유 환경과 변화.
2. **집에서 듀얼 EPYC를 굴린 4개월** — AI와 메모리 대역폭에 대한 가설, 실제 구성, 관찰과 전력·비용.
3. **BC-250을 두 대 산 이야기** — 구매 동기와 실제 시도 수집 후 작성.
4. **내 NAS는 직접 만들기로 했다** — 구성 선택, 사용 목적, 구축 과정과 불편.
5. **노트북 케이스와 냉각에 손을 댄 이유** — 원래 문제, 바꾼 구조, 사용 후 관찰.
6. **군 복무 중 친구와 공유한 원격 개발 환경** — Threadripper·NAS·스마트 플러그 구성과 운영.
7. **OLED 밝기 편차를 카메라로 측정하는 실험** — 측정 조건, 보정 전후 비교, 물리적 열화 복구와의 차이.
8. **생성형 AI를 쓰면서 무엇이 내 실력으로 남는가** — 도구 사용, 코드 이해·검증·수정의 실제 사례.

하드웨어 사양의 이력은 확인이 필요하다. 지원서의 “EPYC 7452 듀얼·RAM 240GB”와 GitHub 소개의 “EPYC 32코어·256GB”는 시점이 다른 구성일 수 있다. 확인 전에는 하나의 구성으로 합치지 않는다.
