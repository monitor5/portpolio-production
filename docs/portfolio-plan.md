# 포트폴리오 기획 v0.5 — Apple 스타일 세로 스토리

현재 방향은 [Apple 스타일 디자인](apple-direction.md)과 실제 구현 코드가 기준이다. 2026-09-21 사용자 지정 레퍼런스 cwaitt.dev를 반영했다. 이전의 가로 스와이프·다섯 장 시안은 사용자 피드백으로 폐기했다.

## 목적과 캐릭터

개발 직무 취업·인턴 지원. AI·데이터·ML 엔지니어링과 백엔드·서버 개발을 중심으로 한다. 하드웨어·서버 변태라는 캐릭터와 직접 만들고 실험해 온 이야기를 살린다.

첫 화면 문구: **“삽질부터 AI까지. 호기심으로 이어봅니다.”**

소개 문구: “호기심이 생긴다면, 직접 구상하고 실험하여 원하는 것들을 만들어봅니다.”

기계를 뜯고, 서버를 굴리고, AI와 서비스를 만드는 사람의 이야기를 위에서 아래로 읽는다. 여행갈매기의 개인 역할·수상·배포, 연구·출판을 근거로 보여주고, 하드웨어를 오래 사용하고 직접 개조한 경험은 별도 상세로 연결한다. 홈은 큰 숫자 대신 삽질이 커져 온 경험의 제목과 요약으로 구성한다. 수상·공저 강조 배지는 메인에서 제거한다. BIUM은 사용자의 최신 지시에 따라 유지한다.

## 정보 구조

- **Story `/`:** 큰 타이포그래피에서 시작해 제작 배경, 서비스, 하드웨어, 연구, 사람으로 이어지는 세로 서사.
- **Projects `/projects`:** Product / AI·Data / Backend·Server 필터와 개별 프로젝트 상세. 여행갈매기는 세 분야에 모두 포함한다.
- **HW / Server `/lab`:** TR 2990WX, EPYC, BC-250, NAS, 개조 노트북의 목록과 각각의 상세.
- **AI / Research `/ai`:** AI 적용·연구·집필, 논문·책의 서지와 출처, AI 프로젝트.
- **GitHub:** 외부 공개 연락·코드 경로. 개인 이메일과 이력서는 자료 확보 후 추가.

본문을 가로로 넘기거나 세로 휠을 다른 방향으로 바꾸지 않는다. 고정 내비게이션과 독립 주소, 뒤로가기, 프로젝트 필터 복원, 모바일 메뉴를 제공한다.

## 콘텐츠 원칙

프로젝트별로 문제, 개인 역할, 기술 구성, 결과와 상태를 읽을 수 있게 한다. 여행갈매기 이외에 개인 담당 범위를 확정하지 않은 항목은 저장소 문서 기준으로 설명하고 이를 상세에 표시한다. 원작을 포크한 뒤 작업이 거의 없었던 터보퀀트 등은 제외한다.

하드웨어 경험은 성공 여부와 관계없이 실제로 시도한 내용과 관찰을 담는다. TR·EPYC의 개별 사용 기간을 합산하거나 무중단 가동 시간으로 표현하지 않는다. 두 대 구매만으로 BC-250 클러스터 구축을 주장하지 않는다.

사진은 사용자가 제공한다. 현재 여행갈매기 화면은 사용자가 제공한 개발단 사이트의 실제 공개 화면을 사용한다. 하드웨어 사진이 들어오기 전에는 실제 경험과 타이포그래피로 내용을 구성하고 가짜 작동 이미지나 계기판을 만들지 않는다.

## 구현 현황과 다음 콘텐츠 작업

Vite 기반 로컬 사이트에 홈, 분야별 목록, 프로젝트 6개·하드웨어 5개·논문/책 상세를 구현했다. 화이트·실버 기본 톤, 푸른색·보라색 그라데이션 제목, 중앙 소개와 둥근 프로젝트 카드로 디자인했다. 다크 모드를 제공하며 실제 서비스 화면과 세로 본문, 독립 상세를 유지한다.

다음 콘텐츠 작업은 하드웨어 사진과 구체적 개조 과정, 여행갈매기의 설계 판단·문제 해결 사례, 다른 대표 프로젝트의 개인 기여 정리다. 상세한 질문은 [추가 수집 항목](content-intake.md)에 있다. 외부 배포는 아직 진행하지 않았다.

## 다국어

기본 영어, 한국어와 일본어를 전체 지원한다. 별도의 언어 선택 화면 없이 바로 내용을 보여주고, 헤더에서 언어를 바꿀 수 있다. 원본 이미지·서지 표기는 보존하고 주변 UI·설명·접근성 문구·메타데이터를 번역한다. [다국어 구현](i18n.md)을 기준으로 관리한다.
