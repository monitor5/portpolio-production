# English · 한국어 · 日本語

기본 언어는 영어다. 한국어와 일본어도 홈·목록·상세 페이지 전체에서 선택할 수 있다. 2026-09-21 적용.

## 언어 선택과 URL

- 상단 `EN / KO / JA` 메뉴에서 English, 한국어, 日本語를 선택한다.
- 우선순위는 **유효한 URL 언어 → 저장된 사용자 선택 → 영어**다. 브라우저 언어로 자동 변경하지 않는다.
- `?lang=en`, `?lang=ko`, `?lang=ja`로 특정 언어의 페이지를 공유할 수 있다.
- 예: `/projects/galmegi?lang=ja`, `/lab/epyc?lang=en#part-1`.
- 내부 링크는 현재 언어와 경로·앵커를 유지한다. 외부 사이트 링크는 변경하지 않는다.
- 언어를 변경해도 현재 상세 페이지, 앵커, 읽던 위치, 프로젝트 필터와 테마를 유지한다.
- 선택은 로컬 브라우저의 `portfolio-locale`에 저장한다. 저장소 사용이 막혀도 현재 화면과 언어 URL은 동작한다.
- 기존의 언어 없는 링크도 계속 동작한다. 첫 방문에서는 영어로 표시한다.

## 번역 범위

홈과 분야별 목록, 프로젝트 6개, 하드웨어 5개, 논문·책 상세를 포함한 17개 페이지를 모두 지원한다.

- 제목, 본문, 역할·기간·진행 상태, 프로젝트 필터와 결과 수.
- 메뉴, 버튼, 푸터, 404 화면과 외부 링크의 새 탭 안내.
- 화면 낭독기용 이름, 이미지 대체 텍스트, 메뉴·테마 전환 문구.
- 페이지 제목과 설명, HTML `lang`, Open Graph 언어, `hreflang` 대체 주소.
- 언어에 맞는 글꼴과 줄바꿈. 영어 프로젝트 개수의 단수·복수 구분.

## 원본 자료의 언어

책 표지와 서비스 스크린샷은 실제 한국어 원본을 유지한다. 영어·일본어 대체 텍스트와 설명에서 원본 언어를 명시한다.

논문의 영어 제목은 KCI에 등록된 공식 영문 제목이다. 책의 영어·일본어 제목과 논문의 일본어 제목은 화면용 참고 번역이며, 외국어판 출간을 의미하지 않는다. 국제 언어 화면에 이 차이를 설명하고 한국어 원제를 함께 표시한다.

서지의 저자 이름은 원본 표기를 보존하고 `lang="ko"`를 지정한다. 기술 제품명·저장소명·DOI·ISBN·URL과 성과 수치는 번역 과정에서 변경하지 않는다. 영문 이름은 기존 KCI 표기인 `U Hyun Kim`을 사용한다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `src/i18n.js` | 언어 선택, 번역 조회, URL 언어 유지, 콘텐츠 병합 |
| `src/locales/messages.js` | UI 문구. 각 키에 영어·한국어·일본어를 한 행으로 관리 |
| `src/data.js` | 원본 사실과 한국어 상세 문구 |
| `src/locales/content.en.js` | 프로젝트·하드웨어·출판 영문 |
| `src/locales/content.ja.js` | 프로젝트·하드웨어·출판 일본어 |
| `src/locales/content.ko.js` | 한국어 분류명 등 추가 현지화 |
| `src/main.js` | 번역을 사용하는 렌더링, 언어 메뉴, 읽던 위치 복원 |
| `tests/i18n.test.js` | 누락·URL·콘텐츠 구조·원본 사실 보존 검사 |

UI 번역은 평문이며 HTML을 넣지 않는다. 줄바꿈은 `\n`, 변수는 `{count}` 같은 이름을 사용한다. 렌더링 시 문자열을 이스케이프한다. 누락된 번역 키와 변수는 조용히 다른 언어로 대체하지 않고 오류로 드러낸다.

콘텐츠를 추가할 때는 세 언어와 테스트를 함께 갱신한다. 원문의 의미와 개인 기여 범위를 보존하고, 번역 과정에서 새 기술·성능·수상·직책을 만들지 않는다.

```sh
npm run build
```

- 자동 테스트 9개: 기본 언어·우선순위·언어 태그, URL/앵커 유지, 외부 링크 보존, 문구 키·변수 일치, 콘텐츠 구조와 사실 보존, BIUM 유지, 영어 미번역 문구 검사.
- 브라우저에서 17개 페이지 × 3개 언어의 제목·본문·내부 링크와 데스크톱 너비를 확인했다.
- 320px에서 같은 페이지들을 검사했고, 일본어 상세 정보 표의 긴 문구가 넘치던 세 페이지를 수정 후 다시 확인했다.
- 언어 변경 후 필터·뒤로가기, 같은 문단의 위치, 저장된 언어 선택 유지와 키보드 언어 메뉴를 확인했다.

외부 호스팅에는 배포하지 않았으며 로컬 미리보기는 `http://127.0.0.1:4387/`다.
